# JARVIS ULTIMATE AI

A native Kotlin Android voice-assistant project targeting Android 12 and newer.

## First milestone

- Dark navy and cyan JARVIS-inspired dashboard
- Tap-to-talk speech recognition
- Spoken responses using Android text-to-speech
- Safe offline commands to open common apps and launch Google Search or Maps
- Clear microphone permission and privacy messaging

## Build

Open the project in Android Studio, allow Gradle sync, then select **Build > Build APK(s)**. The first milestone is a starter app; wake-word listening and the online AI backend are later milestones and are not yet implemented.

## Security

Never commit API keys, passwords, or private tokens. Any future backend credentials must be stored server-side.
